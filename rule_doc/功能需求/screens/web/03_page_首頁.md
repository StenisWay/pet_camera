# 畫面規格書(Web):首頁(Dashboard)

| 項目 | 內容 |
|---|---|
| 平台 | Web(桌面瀏覽器) |
| 對應功能規格書 | `../../04_spec_裝置管理.md`(裝置列表資料來源)、`../../03_spec_裝置配對.md`(新增裝置入口) |
| 所屬導覽層級 | 頂部導覽「首頁」項目,路由 `/dashboard`(見 `02_page_導覽與全域結構.md`) |

## 1. 畫面用途

登入後的預設頁面,列出使用者所有已配對的鏡頭,點擊進入指定鏡頭的攝影機畫面。

## 2. 版面配置

- 頂部:麵包屑或頁面標題「首頁」、右上角「新增裝置」按鈕。
- 主體:裝置卡片**網格**(桌面寬螢幕可一列顯示 3~4 張卡片,依視窗寬度自適應排列,不像 App 版受限於單欄),每張卡片顯示:裝置名稱、線上/離線狀態標示、最近一筆事件縮圖(若有)。
- 點擊卡片 → 進入 `04_page_攝影機畫面.md` 對應路由(`/dashboard/devices/{id}`),並帶入該 `device_id`。
- 點擊「新增裝置」→ 進入裝置配對流程(見 `../../03_spec_裝置配對.md`),完成後新裝置卡片加入網格。

## 3. 空狀態

尚未配對任何裝置時,主體區域顯示引導文案(「新增你的第一台鏡頭」)+ 「新增裝置」大按鈕,取代裝置卡片網格。

## 4. 讀取狀態與錯誤碼

沿用 `../../04_spec_裝置管理.md` 第 4、5 節(裝置列表載入 skeleton、DEVICE_004/DEVICE_005),本文件不重複定義。
