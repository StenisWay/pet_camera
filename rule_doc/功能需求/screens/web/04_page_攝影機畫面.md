# 畫面規格書(Web):攝影機畫面

| 項目 | 內容 |
|---|---|
| 平台 | Web(桌面瀏覽器) |
| 對應功能規格書 | `../../06_spec_即時串流.md`(即時畫面)、`../../08_spec_時間軸與事件歷史.md`(歷史紀錄)、`../../11_spec_剪輯與截圖.md`(截圖/剪輯) |
| 進入路徑 | 由首頁裝置卡片點擊進入(路由 `/dashboard/devices/{id}`),或推播通知 deep link 進入 |
| 所屬導覽層級 | 獨立路由,頂部導覽列維持顯示(見 `02_page_導覽與全域結構.md`) |

## 1. 畫面用途

顯示指定鏡頭的即時畫面或歷史錄影回放,並提供截圖/剪輯操作。

## 2. 版面配置

雙欄配置(桌面螢幕寬度足夠,即時畫面與歷史列表**同時顯示**,不需分頁切換,這是與 App 版最主要的差異):

- 頂部:麵包屑「首頁 > {裝置名稱}」、線上/離線狀態。
- 主欄(左側,約佔寬度 65%):即時畫面(見 `../../06_spec_即時串流.md`),下方為截圖按鈕(即時或回放皆可點擊)、回放模式下額外顯示「剪輯」按鈕。
- 側欄(右側,約佔寬度 35%):過去一個月的事件列表(見 `../../08_spec_時間軸與事件歷史.md`),獨立捲動。點擊列表項目後,**主欄畫面切換為該事件回放**,側欄列表本身不受影響、仍可繼續瀏覽其他事件。

## 3. 互動細節

- 點擊側欄任一歷史事件時,主欄由即時畫面切為該事件回放,等同結束目前的 WebRTC 連線(見 `../../06_spec_即時串流.md` 第 2.1 節)。
- 主欄提供「返回即時畫面」按鈕,點擊後重新建立直播連線。
- 側欄與主欄為同一頁面內的兩個獨立區塊,不像 App 版是分頁切換,因此側欄捲動位置在主欄內容改變時不會重置。
- 點擊「剪輯」按鈕開啟剪輯範圍選取元件(起訖時間拖曳軸),確認後送出剪輯請求(見 `../../11_spec_剪輯與截圖.md` 第 2.2 節)。

## 4. 讀取狀態與錯誤碼

即時畫面沿用 `../../06_spec_即時串流.md` 第 6、7 節;歷史列表沿用 `../../08_spec_時間軸與事件歷史.md` 第 6、7 節;截圖/剪輯沿用 `../../11_spec_剪輯與截圖.md` 第 4、5 節。本文件不重複定義。左右兩欄各自獨立呈現讀取/錯誤狀態,不互相影響(如側欄列表載入失敗,不影響主欄即時畫面正常播放)。
