| 項目 | 內容 |

| 平台 | Web(桌面瀏覽器) |

| 所屬導覽層級 | 頂部導覽「會員」項目,路由 `/account`(見 `02_page_導覽與全域結構.md`) |

## 1. 畫面用途

顯示使用者帳號資訊,並作為裝置管理、帳號設定、登出的入口。

## 2. 版面配置

- 頂部:使用者 Email、註冊日期。
- 選單列表(由上到下):
  1. 裝置管理 → 進入裝置列表管理頁(重新命名/移除,見 `../../04_spec_裝置管理.md`)
  2. 修改密碼/設定密碼 → 進入修改密碼或設定密碼表單(依帳號是否已設定過密碼顯示,見 `../../05_spec_帳號設定.md` 第 2.1 節)
  3. 通知設定 → 進入通知授權狀態頁(見 `../../09_spec_推播通知.md` 第 5 節)
  4. 登出(需二次確認,見 `../../02_spec_登入註冊與密碼重設.md` 第 2.5、2.6 節)
  5. 刪除帳號(需二次確認,依帳號是否已設定過密碼以密碼或 Email 文字驗證,見 `../../05_spec_帳號設定.md` 第 2.2 節)

Web 版選單**包含登出項目**——Web 使用短效 access token + refresh token,登出會真正撤銷 refresh token,詳見 `../../02_spec_登入註冊與密碼重設.md` 第 2.3.1 節。
