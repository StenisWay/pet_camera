# 畫面規格書(App):攝影機畫面

| 項目 | 內容 |
|---|---|
| 平台 | 手機原生 App(iOS/Android) |
| 對應功能規格書 | `../../06_spec_即時串流.md`(即時畫面)、`../../08_spec_時間軸與事件歷史.md`(歷史紀錄)、`../../11_spec_剪輯與截圖.md`(截圖/剪輯) |
| 進入路徑 | 由首頁裝置卡片點擊進入,或推播通知 deep link 進入 |
| 所屬導覽層級 | Push 導覽,無底部導覽列(見 `02_page_導覽與全域結構.md`) |

## 1. 畫面用途

顯示指定鏡頭的即時畫面或歷史錄影回放,並提供截圖/剪輯操作。

## 2. 版面配置

單欄直向配置(受限於手機螢幕寬度,即時畫面與歷史列表以分頁切換而非同時顯示):

- 頂部:返回按鈕、裝置名稱、線上/離線狀態。
- 影像區:預設顯示即時畫面(見 `../../06_spec_即時串流.md`),寬度撐滿螢幕。
- 影像區下方操作列:截圖按鈕(即時或回放皆可點擊)、若目前為回放模式則額外顯示「剪輯」按鈕。
- 影像區下方:分段切換「即時」/「歷史」。
  - 「即時」:即時串流畫面(見 `../../06_spec_即時串流.md`)。
  - 「歷史」:過去一個月的事件列表(見 `../../08_spec_時間軸與事件歷史.md`),點擊列表項目後影像區切換為該事件回放。

## 3. 互動細節

- 從「即時」切到「歷史」會結束目前的 WebRTC 連線(見 `../../06_spec_即時串流.md` 第 2.1 節離開頁面即釋放連線的規則,此處視為切換視為離開直播)。
- 從「歷史」切回「即時」重新建立直播連線。
- 點擊「剪輯」按鈕開啟剪輯範圍選取元件(起訖時間拖曳軸),確認後送出剪輯請求(見 `../../11_spec_剪輯與截圖.md` 第 2.2 節)。

## 4. 讀取狀態與錯誤碼

即時畫面沿用 `../../06_spec_即時串流.md` 第 6、7 節;歷史列表沿用 `../../08_spec_時間軸與事件歷史.md` 第 6、7 節;截圖/剪輯沿用 `../../11_spec_剪輯與截圖.md` 第 4、5 節。本文件不重複定義。
