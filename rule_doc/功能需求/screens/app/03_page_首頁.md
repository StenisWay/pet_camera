# 畫面規格書(App):首頁(Dashboard)

| 項目 | 內容 |
|---|---|
| 平台 | 手機原生 App(iOS/Android) |
| 對應功能規格書 | `../../04_spec_裝置管理.md`(裝置列表資料來源)、`../../03_spec_裝置配對.md`(新增裝置入口) |
| 所屬導覽層級 | 底部導覽「首頁」分頁(見 `02_page_導覽與全域結構.md`) |

## 1. 畫面用途

登入後的第一個畫面,列出使用者所有已配對的鏡頭,點擊進入指定鏡頭的攝影機畫面。

## 2. 版面配置

- 頂部:App 名稱/標題列,右上角「新增裝置」圖示按鈕。
- 主體:單欄卡片直向列表(受螢幕寬度限制,一行一張卡片),每張卡片顯示:裝置名稱、線上/離線狀態標示、最近一筆事件縮圖(若有)。
- 點擊卡片 → 進入 `04_page_攝影機畫面.md`,並帶入該 `device_id`。
- 點擊「新增裝置」→ 進入裝置配對流程(見 `../../03_spec_裝置配對.md`),完成後新裝置卡片加入列表。

## 3. 空狀態

尚未配對任何裝置時,主體區域顯示引導文案(「新增你的第一台鏡頭」)+ 「新增裝置」大按鈕,取代裝置卡片列表。

## 4. 讀取狀態與錯誤碼

沿用 `../../04_spec_裝置管理.md` 第 4、5 節(裝置列表載入 skeleton、DEVICE_004/DEVICE_005),本文件不重複定義。
