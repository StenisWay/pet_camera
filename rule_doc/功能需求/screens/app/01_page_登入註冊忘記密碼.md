# 畫面規格書(App):登入 / 註冊 / 忘記密碼

| 項目 | 內容 |
|---|---|
| 平台 | 手機原生 App(iOS/Android) |
| 對應功能規格書 | `../../02_spec_登入註冊與密碼重設.md`(行為、API、錯誤碼、讀取狀態皆定義於該文件,本文件僅描述版面與導覽) |
| 所屬導覽層級 | 未登入狀態的獨立流程,不屬於底部導覽(見 `02_page_導覽與全域結構.md`) |

## 1. 畫面用途

使用者尚未登入時的入口流程,完成後進入首頁(見 `03_page_首頁.md`)。App 登入後依 `02_spec_登入註冊與密碼重設.md` 第 2.3.2 節取得長效 token,長期保持登入狀態,此流程平時只在首次安裝或 token 過期時出現。

## 2. 畫面組成與導覽動線

```
[登入頁] --點擊「註冊」--> [註冊頁] --註冊成功--> [登入頁]
[登入頁] --點擊「忘記密碼」--> [忘記密碼頁] --送出--> [忘記密碼已送出提示]
[Email 內連結] --開啟--> [重設密碼頁] --重設成功--> [登入頁]
[登入頁] --登入成功--> [首頁]
```

各畫面為全螢幕直向表單,單欄配置,鍵盤彈出時表單自動上移避免遮擋輸入欄位。

### 2.1 登入頁

- 元素:Email 欄位(鍵盤類型:email)、密碼欄位(安全輸入,預設遮蔽)、登入按鈕、分隔線(「或」)、「使用 Google 繼續」按鈕、「使用 Apple 繼續」按鈕、「忘記密碼」文字連結、「還沒有帳號?註冊」文字連結。
- 為 App 啟動時的預設畫面(當本機無有效 token 時)。
- 第三方登入按鈕點擊後喚起對應原生 SDK(Google Sign-In / Sign in with Apple)流程,行為與錯誤提示見 `../../02_spec_登入註冊與密碼重設.md` 第 2.7 節,本文件不重複定義。

### 2.2 註冊頁

- 元素:Email 欄位、密碼欄位、密碼強度提示文字(即時顯示是否符合規則)、註冊按鈕、分隔線(「或」)、「使用 Google 繼續」按鈕、「使用 Apple 繼續」按鈕、「已有帳號?登入」文字連結。
- 欄位規則與即時驗證訊息見 `../../02_spec_登入註冊與密碼重設.md` 第 2.1 節,本文件不重複定義。
- 註冊成功導回登入頁,不自動登入。
- 本頁的第三方登入按鈕與登入頁為同一組操作(建立新帳號或登入既有帳號皆由後端依 2.7 節規則判斷),UI 上不需與登入頁區分。

### 2.3 忘記密碼頁

- 元素:Email 欄位、送出按鈕。
- 送出後畫面切換為單一提示文字(「若該 Email 存在,重設連結已寄出」)+「返回登入」按鈕,不停留在表單狀態。

### 2.4 重設密碼頁

- 由 Email 內連結透過 Universal Link(iOS)/ App Link(Android)開啟,直接進入 App 內對應頁面,不會落在瀏覽器。
- 元素:新密碼欄位、確認新密碼欄位(需一致,規則見 `../../02_spec_登入註冊與密碼重設.md` 第 2.1 節)、送出按鈕。
- Token 無效/過期時,整頁替換為錯誤狀態(見功能規格書 AUTH_007),不顯示表單。
