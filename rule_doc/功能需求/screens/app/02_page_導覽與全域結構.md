# 畫面規格書(App):底部導覽與全域結構

| 項目 | 內容 |
|---|---|
| 平台 | 手機原生 App(iOS/Android) |
| 對應功能規格書 | 無獨立功能規格,純導覽結構定義 |
| 適用範圍 | 所有已登入後的畫面 |

## 1. 導覽結構

登入成功後,App 進入三個底部導覽分頁(Tab bar):

| Tab | 對應畫面規格書 | 說明 |
|---|---|---|
| 首頁 | `03_page_首頁.md` | 裝置列表,預設分頁 |
| 相簿 | `05_page_相簿.md` | 使用者保存的照片/剪輯 |
| 會員 | `06_page_會員資料.md` | 帳號與裝置管理入口 |

## 2. 非分頁畫面(Push 導覽,無底部導覽列)

以下畫面由 Tab 內頁面點擊進入,進入後隱藏底部導覽列,提供返回按鈕回到來源 Tab:

- `04_page_攝影機畫面.md`(由首頁裝置卡片點擊進入)

## 3. 規則

- 底部導覽列在三個 Tab 之間切換時,各 Tab 保留自身的捲動位置與狀態(如首頁捲到一半切去相簿再切回來,首頁維持原捲動位置)。
- 推播通知點擊後的 deep link(見 `../../09_spec_推播通知.md`)導向攝影機畫面,並在返回時回到首頁而非強制切換 Tab。
- Tab 圖示 + 文字並列顯示,符合原生平台的 Tab bar 慣例(iOS/Android 皆同一套設計,不做系統別差異化)。
