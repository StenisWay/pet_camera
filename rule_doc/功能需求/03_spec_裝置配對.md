## 1. 使用者故事

作為使用者,我想第一次使用時把家裡的鏡頭跟我的帳號配對起來。

## 2. 功能說明

### 2.1 配對碼產生

鏡頭開機後呼叫 `/devices/register` 向後端註冊,取得配對碼(`devices.pairing_code`),有效期 10 分鐘。

### 2.2 配對

使用者於 App/Web 輸入配對碼,呼叫 `/devices/pair`。後端驗證配對碼有效、未過期、未被使用,綁定該裝置的 `user_id`,狀態改為 `paired`,清除 `pairing_code`。配對成功後導向裝置命名畫面。

### 2.3 連線狀態回報

配對完成後,鏡頭每 30 秒呼叫 `/devices/{device_id}/heartbeat` 更新 `last_seen_at`。超過 90 秒未回報,狀態視為 `offline`。此狀態顯示於裝置管理頁(`04_spec_裝置管理.md`)。

## 3. API 介面

| Method | Path | 說明 |
|---|---|---|
| POST | `/devices/register` | 鏡頭端呼叫,取得配對碼 |
| POST | `/devices/pair` | 使用者輸入配對碼完成綁定 |
| POST | `/devices/{device_id}/heartbeat` | 鏡頭端心跳回報 |

## 4. 讀取狀態

| 階段 | UI 呈現 |
|---|---|
| 配對碼驗證中 | 輸入框下方顯示「驗證中...」 |
| 配對成功 | 導向裝置命名畫面 |

## 5. 錯誤碼

| 錯誤碼 | HTTP Status | 說明 | 使用者訊息 | 呈現方式 |
|---|---|---|---|---|
| DEVICE_001 | 410 | 配對碼過期 | 配對碼已過期,請重新產生 | Inline 於配對輸入框 |
| DEVICE_002 | 400 | 配對碼錯誤 | 配對碼錯誤 | Inline 於配對輸入框 |
| DEVICE_003 | 409 | 裝置已被其他帳號配對 | 此裝置已被配對 | 阻斷式對話框 |

## 6. 驗收標準

- [ ] 使用者可用配對碼成功綁定一台鏡頭
- [ ] 配對碼過期後顯示 DEVICE_001,無法再用於配對
- [ ] 配對碼輸入錯誤顯示 DEVICE_002
- [ ] 已被配對的裝置再次被輸入配對碼時顯示 DEVICE_003
- [ ] 鏡頭持續回報心跳時,裝置狀態維持 `paired`;停止回報超過 90 秒後狀態轉為 `offline`
