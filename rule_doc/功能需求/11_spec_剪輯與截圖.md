# 功能規格書:剪輯與截圖(F5)

| 項目 | 內容 |
|---|---|
| 優先級 | P1 |
| 相依功能 | F1(即時串流)、F3(時間軸,剪輯來源可為歷史事件) |
| 資料模型 | `01_資料模型與儲存規格.md` — `media_items` 表、相簿項目狀態機 |
| 共用規範 | `10_錯誤處理與狀態規範.md` |

## 1. 使用者故事

1. 作為使用者,我在看即時畫面或歷史事件時,想截一張照片保存下來。
2. 作為使用者,我想從一段歷史錄影裡剪出一小段保存到相簿。

## 2. 功能說明

### 2.1 截圖

使用者於攝影機畫面(即時串流或事件回放)點擊截圖按鈕。後端依當下時間戳從對應影像來源擷取一幀,產生照片檔,建立 `media_items` 紀錄(`type = photo`),`status = processing` 轉 `ready`。

### 2.2 剪輯

使用者於歷史事件回放頁選擇起訖時間點(僅能剪輯保留期內、`status = ready` 的事件影片),送出剪輯請求。後端非同步裁切影片,完成後建立 `media_items` 紀錄(`type = clip`),`status = processing` 轉 `ready`。

- 單次剪輯長度上限:5 分鐘。
- 剪輯來源僅限單一事件影片內的時間範圍,不支援跨事件合併剪輯。

## 3. API 介面

| Method | Path | 說明 |
|---|---|---|
| POST | `/devices/{device_id}/screenshot` | 即時畫面截圖 |
| POST | `/events/{event_id}/screenshot` | 事件回放畫面截圖 |
| POST | `/events/{event_id}/clip` | 剪輯請求(附起訖秒數) |
| GET | `/media/{media_item_id}` | 查詢處理狀態與內容 |

## 4. 讀取狀態

| 階段 | UI 呈現 |
|---|---|
| 點擊截圖按鈕 | 按鈕短暫 disable,截圖成功以 Toast 提示「已保存至相簿」 |
| 送出剪輯請求後 | 顯示「處理中」提示並停留於當前頁面,不阻塞其他操作(背景處理) |
| 相簿內對應項目 | `status = processing` 時卡片顯示 spinner + 「處理中」;`ready` 後可正常瀏覽播放 |

## 5. 錯誤碼

| 錯誤碼 | HTTP Status | 說明 | 使用者訊息 | 呈現方式 |
|---|---|---|---|---|
| CLIP_001 | 410 | 剪輯來源影片已過保留期或不存在 | 此片段已無法剪輯 | Toast |
| CLIP_002 | - | 剪輯處理失敗 | 剪輯失敗,請重試 | 相簿卡片內嵌錯誤圖示 |
| CLIP_003 | 400 | 剪輯長度超過 5 分鐘上限 | 單次剪輯最長 5 分鐘 | Inline 於剪輯時間選取元件 |
| SCREENSHOT_001 | - | 截圖來源不存在或已過期 | 截圖失敗 | Toast |

## 6. 驗收標準

- [ ] 使用者可在即時畫面截圖,成功後相簿可查詢到該照片
- [ ] 使用者可在歷史事件回放截圖
- [ ] 使用者可從歷史事件剪輯出指定時間範圍的短片,完成後相簿可查詢到該剪輯
- [ ] 剪輯長度超過 5 分鐘時顯示 CLIP_003,無法送出
- [ ] 剪輯來源已過保留期時顯示 CLIP_001,不可發起剪輯
- [ ] 剪輯/截圖處理中時,相簿卡片顯示處理中狀態,完成前不可點擊播放
